# ADR-0030: Agent skills for Phone MCP tool use

- **Status:** Accepted
- **Date:** 2026-10-14
- **Context:** The server exposes 41 tools across sensing, capture, radio, UI automation, and network inspection, plus a pairing/TLS/media transport with kill-switches, foreground grants, ALPN, and single-stream limits. Agents without procedural guidance underuse tools, miss guardrails (default-OFF `audio_*`/`camera_*`/`net_*`/`ui_*`/`ble_write`), mishandle `isError:true` vs RPC codes, inline blobs instead of following `/media` URLs, or open second SSE streams (`-32603`). A skills.sh search finds no phone-mcp skill (one irrelevant 1-install hit); related `android-device-automation` (5.7K) and `mcp-builder` (126K) cover adjacent workflows, not this tool surface. The Agent Skills open standard (Anthropic, Dec 2025; `agentskills.io/specification`) defines the interop format every major harness reads: a directory with `SKILL.md`, frontmatter `name` (<=64 chars, lowercase-hyphens) + `description` (<=1024 chars), body under ~5000 tokens, progressive disclosure via `references/`. OpenCode discovers project skills at `.agents/skills/*/SKILL.md`.
- **Decision:** Ship six model-invoked project skills in `.agents/skills/`: `phone-mcp` (router: pairing, TLS pinning, timeouts, media, error taxonomy, domain routing) plus `phone-mcp-sense` (5 tools), `phone-mcp-capture` (9), `phone-mcp-wireless` (8), `phone-mcp-ui` (6), `phone-mcp-net` (13) = 41/41 coverage. Each `SKILL.md` stays under 500 words with steps ending in checkable completion criteria; arg clamps, batch shapes, and troubleshooting live in `references/`. Frontmatter carries only spec fields (`name`, `description`) so `scripts/verify-skills.py` (75 checks: spec, budgets, layout, coverage) gates conformance.
- **Alternatives considered:** (a) Single monolithic skill — rejected: sprawl past the token budget, high per-turn context load, premature-completion risk. (b) Per-tool skills (41) — rejected: 41 descriptions permanently in context, maintenance cost, violates YAGNI. (c) Install an ecosystem skill — rejected: none covers the TOFU/TLS, kill-switch, media-TTL, or GATT/VPN/UI-guard semantics; verified via `npx skills find`.
- **Consequences:** + Agents route deterministically (router + distinct leading words per domain), guardrails and transport rules have one source of truth, coverage is machine-checked. − New surface to keep in sync with `McpRouter`/`*Provider` (same rule as `README.md`/`docs/api.md`); `scripts/verify-mcp.sh` stays the live-transport gate while `verify-skills.py` is the static-skills gate.
