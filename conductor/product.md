# Phone MCP — Product Overview

## Description
Phone MCP is an Android application that exposes physical smartphone hardware and system I/O (Camera, Microphone, Location, Bluetooth LE, UI Automation, Network Inspection) as a local Model Context Protocol (MCP) server over streamable HTTPS with Bearer token authentication and self-signed TLS TOFU.

## User Persona
- AI developers and autonomous agents needing real-world phone interaction.
- Security-conscious users operating on local networks with strict hardware kill-switches.

## Core Value Proposition
- 100% on-device, local LAN server with zero cloud telemetry.
- Hardware kill-switches ensuring agent access is strictly user-controlled.
- Modern, clean, professional, and accessible Android UI.
